Notes

  • Atlas needs a better source. The block and the figure are the same marble, so the silhouette does nothing; the render separates them by surface texture and it is still soft. A raking-light photo, or a hand-drawn mask, fixes it.
  • Awakening is the safer version of the same idea. The twist of the torso gives it a real silhouette, which is why it holds better here.
  • Field code changes either way. Particles currently ride stroke centre-lines. Any of these needs a density mask instead, so the animation gets rebuilt regardless of the pick.
